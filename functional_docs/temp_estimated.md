### `temp_estimated` — Temp_Estimated

*Created by this repo.* Python: `models/temp_estimated.py`, `models/x_temp_estimated_gap.py`. Record name field: `name`.

Other repos that use this model: `server action BugFix-Studio-Misc.server_action_2799_mst_odoo_data_clean_up` (BugFix-Studio-Misc)

**Summary:**

<!-- SUMMARY:model:temp_estimated -->
A temporary copy of a sales order line (order, customer, project, product, category, quantities, unit price, UoM and subtotal) attached to a Project Gross Margin estimated or actuals line. Records are created by the 'SRM - RPT - Project Gross Margin' action and shown in the parent line's Sales Order Lines sub-tab.
<!-- /SUMMARY -->
