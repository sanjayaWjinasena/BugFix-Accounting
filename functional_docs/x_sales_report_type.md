**Summary:**

<!-- SUMMARY:model:x_sales_report_type -->
Sales report type master (created by Jinasena_Masterdata_Reporting) that this repo also declares in Python, with a report name and a report code that selects which report logic runs. This repo adds lists of the journal entries, journal items and sales order lines tagged with the type, a form page listing the linked journal items, and an inline-editable list with required name and code.
