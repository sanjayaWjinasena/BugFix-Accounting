**Summary:**

<!-- SUMMARY:model:x_rm_none_moving -->
A line of the 'Slow Moving Items' report run from a Sales Report Model, giving per product the code, category, base price, and received ('In Hand') and issued quantities for each of the last four months. Lines are created by the 'SRM - RPT - Slow Moving Items' action and viewed in a read-only list or through pivot actions.
