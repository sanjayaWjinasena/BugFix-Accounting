**Summary:**

<!-- SUMMARY:model:account.move.line -->
This repo adds 57 fields to journal items. They cover payroll EPF/ETF data read from the employee contract (NIC, EPF/ETF numbers, member and employer contributions, earnings, bank details), related data from the parent entry (partner, status, project, journal type, payment status), credit limits, report type links and many unused Studio placeholders. Automations link journal items to an HR contract by analytic account, set the incentive report type on income lines, and set the Account Mandatory flag from analytic distribution models. Studio views reshape journal item lists into EPF, ETF and Bank Data report layouts, and the repo adds 45 window actions and ten record rules.
